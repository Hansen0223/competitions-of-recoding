## 七、筛选方法论

1. **中奖率优先看「获奖名额 ÷ 参赛队伍」**，而不是奖金池总额。
   例：Smart Buildings 22 个名额 / 208 队 ≈ 10.6%，远高于大池子万队赛。
2. **论文奖 / Writeup 奖是隐藏机会**：即使榜单打不过，写清楚方法仍有独立奖金池（Smart Buildings、AIMO、Aura 等均设）。
3. **社区赛 > Featured 赛**：Kaggle 社区赛队伍常只有几十个，奖金却可达 $10k。
4. **"可报名"标签不等于真能参加**：DataFountain 部分赛事日期已过仍显示可报名；天池余震赛页面写"立即报名"但规则注明报名已截止。务必看规则页。
5. **避开付费型/营销型比赛**：收报名费、要求转发朋友圈攒赞换证书的，不符合"纯线上拿奖金"目标。
